# Executive Sales & Profitability Dashboard

## 📊 Project Overview

This project presents an interactive sales analytics dashboard
developed using Microsoft Excel. It provides a comprehensive
overview of sales performance, revenue, profitability, and
regional sales trends through visualizations and interactive filters.

## 🎯 Project Objectives

- Analyze total revenue and gross profit.
- Monitor gross profit margin and cost of goods sold (COGS).
- Track total units sold and total orders.
- Evaluate monthly revenue and profit trends.
- Identify top-performing countries by revenue.
- Analyze revenue contribution by sales channel.
- Compare sales performance across European regions.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Analysis
- Data Visualization

## 📈 Dashboard Features

- KPI Cards for key sales and profitability metrics.
- Monthly Revenue and Gross Profit Trend Analysis.
- Top 5 Countries by Revenue.
- Revenue Share by Sales Channel.
- Region-wise Sales Performance Comparison.
- Country-wise Revenue Map.
- Interactive filters for Product Category, Country, and Quarter.

## 📂 Workbook Structure

- Data: Contains the sales dataset.
- Pivot Tables: Contains summary tables used for analysis.
- Dashboard: Displays interactive visualizations and key metrics.

## 💡 Key Learnings

- Creating interactive dashboards in Excel.
- Using Pivot Tables and Pivot Charts for sales analysis.
- Applying Slicers to filter dashboard results.
- Analyzing revenue, profit, and regional performance.
- Presenting business insights through visualizations.

## 🏁 Conclusion

This project demonstrates the use of Microsoft Excel
for interactive sales reporting and profitability analysis.
The dashboard helps users explore sales trends, compare
regional performance, and understand key business metrics.
